One funny line of awkward small talk a robot says to another robot in an elevator: its proximity sensor knows they are standing too close, its firmware knows better than to say so, so the small talk lands on "nice elevator."

## Run it

```sh
node main.ts
```

The program writes the line to `/output/entry.txt` (121 characters, under the 200-character gate).
